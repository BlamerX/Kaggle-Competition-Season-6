# S6E11 Daily Log

> **⚠️ RULES** — canon laws live in [`_LAWS.md`](_LAWS.md); the rules below are specific to this ledger.
>
> 1. **A score line needs CV *and* a confirmed LB** (Law 2). Entries with no score — setup, record audits, instrument runs — are allowed, and must be labelled `no score entry` so nobody mistakes them for results.
> 2. **DO NOT EDIT** a previous day's entry (Law 6). A correction is a new dated entry that names the entry it corrects and says what changed.
> 3. **PREPEND** new days (latest first), the format block staying first and dated entries written below it. One entry per calendar day, heading `### DD-MM-YYYY`.
> 4. **Include:** Goal, Experiments, Score (when one exists), Timing, Key Learning, Status.
> 5. **Key Learning is what a future arm reads.** Write what changed the plan, not what was run — the run is in `training_logs.md`.
> 6. **Name the closure.** When a day ends an axis, write the falsifier it was closed against and the measurement that satisfied it, or the axis reopens with the next model.
> 7. **Status icons:** 🏆 Best | ✅ Success | ⚠️ Partial | ❌ Failed

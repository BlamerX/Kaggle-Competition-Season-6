- **TL;DR:** The winning submission is a **stacked NN**: level-1 model OOF predictions were fed in as ordinary input *features* of a forked DeepTables notebook, not blended.
- His planned submission (20-fold Ridge ensemble over diverse models, CV 72300) "would have landed me on the second place".
- The NN ensemble had a **worse** CV (72468 = +168 RMSE) yet beat the Ridge ensemble on the LB — the only published case on this board where a *worse-CV model* won the actual LB (5th's worse-CV-looking day-1 pick finished public 626 but 5th private, i.e. CV was right there).
- **Architecture:** CASCADE · stages=2 · l1=SVR(rbf), LGBM, LGBM5, CatBoost-classifier, XGB, AutoGluon-FASTAI [exact member count only in the author's image, not text] · l2=DeepTables NN trained on base features + 4 level-1 OOF columns (no meta-learner blender) ·
  novel=DeepTables · mod=multi-view ·
  topo=CatBoost-classifier outlier proba + SVR oof + LGBM5 oof + XGB preds [4 numeric columns] → DeepTables NN (submitted) ‖ parallel path: 20-fold diverse pool → Ridge = 2nd-place-scoring artifact
  - Stage 1 outputs are consumed **as features**, so the winning path is not an ensemble at all: "The oof predictions were not used in the ensemble. They were used as an additional feature in a LGBM (or the NN for my second final submission)."
  - The `_st` model suffix means "the catboost oofs are included" — the same forward-feed trick inside the GBM branch.
  - The second, discarded-as-winning-artifact path is a genuine `STACK2` (Ridge fitted on the OOF matrix); the author reports both, and 1st place was earned by the cascade.
  - `mod` deliberately omits `pseudo`: he passed `pseudo_data = data_original` to AutoGluon but his own Edit 2 states `fit()` ignores it (`fit_pseudolabel()` is required), so no pseudo-label loop ever ran.
- **Setup:** rows/cols/split sizes not stated; 20 CV folds in the Ridge pipeline; 2 final slots (Ridge ensemble as the first, the NN as the second, chosen spontaneously on the last day).
- Structural quirk exploited: the target's outliers. `bin_price()` flags `price > Q3 + 1.5*IQR` and a CatBoost **classifier** predicts that flag; the probability becomes a feature.
- Original data appended to some models ("even two times in LGBM"), giving per-model views of the same pool.
- **Features:** all categorical features additionally target-encoded into CatBoost, using the **median, not the mean**, recomputed inside every fold ("leakfree").
- LGBM5: label-encoded categoricals with rare categories collapsed into a category named `rare` (same recipe as the NN in his starter notebook), with raised `max_bin`.
- `price_bin = (price < upper_bound).astype(int)` with `Q1 = p25(price)`, `Q3 = p75(price)`, `IQR = Q3-Q1`, `upper_bound = Q3 + 1.5*IQR`, `lower_bound = Q1 - 1.5*IQR` (code quoted verbatim in the post).
- Outlier feature = the classifier's probability of **not** being an outlier; no thresholding (author comment: "I did not use a threshold, I simply used the probabilities as feature").
- AutoGluon-FASTAI branch passed `pseudo_data = data_original` — see Failed: Edit 2 states `fit()` ignores it.
- Dropped columns, GP/generated features: not stated.
- **Models:** CatBoost classifier (Optuna-tuned), `min_data_in_leaf 16`, `learning_rate 0.03355311405703999`, `random_strength 11.663619399375248`, `l2_leaf_reg 17.703146378123996`, `max_depth 10`, `subsample 0.9479174100256215`, `border_count 130`, `bagging_temperature 24.032067560148384`, `early_stopping_rounds 25`, `use_best_model True`, `cat_features = cat_cols`.
- LightGBM (`LGBM5` and a `_st` variant): `loss_function "RMSE"`, `n_estimators 2000`, `max_bin 30000`, `early_stopping_rounds 25`; hyperparameters credited to @noodl35.
- SVR with **rbf** kernel (replacing linear SVR) as suggested by @siukeitin in discussion 532997.
- AutoGluon FASTAI-only run: `eval_metric='rmse'`, `problem_type="regression"`, `num_bag_folds 10`, `num_bag_sets 2`, `time_limit 1800`, `included_model_types ['FASTAI']`, `keep_only_best True`, `presets "best_quality"`, wrapped in a nested CV over 20 folds "to be 100% leakfree".
- XGB predictions "derived from publicly available hyperparameters" (the author says he forgot the source).

- Released notebook (CatBoostClassifier + LGBM1_st + LGBM5_st included) private score 62957.83525, "would have reached a place within the top three".

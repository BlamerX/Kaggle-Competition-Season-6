### S5E6-01 · 1st · cdeotte (Chris Deotte) · LB 0.38450/0.38652 · CV 0.386

- **Link:** https://www.kaggle.com/c/playground-series-s5e6/discussion/587393
- **Status:** FETCHED (/c/ discussion form, first attempt, 32.8 KB incl. comments)
- **TL;DR:** RAPIDS cuDF target-encoding grid over the original dataset plus a GPU hill-climb over 9 members each trained many times (~300 prediction sets); MAP@3 rewarded seed-averaged probabilities.
- **Architecture:** FLAT · stages=2 · l1=9 member slots ≈300 seed-averaged prediction sets (members include internal stage-1 OvR binaries x 7 classes) ·
  l2=top level is GPU hill-climb weights (no meta-learner); members 3/5/8 are STACK2 internals: NN L2 (categorical cross-entropy) and XGB L2 (multi:softprob) ·
  novel=none · mod=ovo,multitarget,pseudo,multi-view ·
  topo=8 categorical cols -> 162 combo cols -> 2268 TE features + [stage-1 XGB/CB/NN/cuML-LR per binary class -> OOF -> NN-L2 + XGB-L2] + public-notebook models -> 9 members x many seeds -> avg probabilities -> GPU hill-climb weights -> top-3 = MAP@3 list
  - How the top-K list is produced: probabilities are averaged across seeds/models FIRST, then the top-3 fertilizer classes are selected — the re-ranking is just argmax-order over calibrated multi-class probabilities, not a separate ranker.
  - Stage decomposition (rule 8): stage-1 models are per-class binary classifiers ("Is the target y=0?", ..., y=6), the L2 NN + L2 XGB recombine them into calibrated 7-class probabilities — that recombination is a genuine second stage inside three of the nine members.
  - Members 4/6/7 are public-notebook models he retrained (bizen250 repeated-KFold XGB, elainedazzio XGB, ricopue Keras NN); member 5 is ayushchandramaurya's public stacking XGB-over-LGBM — public code supplied members, not a public OOF matrix (hence no `public-oof` mod tag: every prediction set in the pool is his own trained).
- **Setup:** 8 feature columns, each treatable as categorical; 7 fertilizer classes = 7 binary targets; train ≈7.5e5 rows (author comment; class-wise sample counts on the S5E6-10 page sum to exactly 750,000); test rows not stated; submission slots not stated.
- Structural quirk exploited (author comment): the original Kaggle source dataset has random targets, so the only signal is the synthetic-generation process itself; merging original-data target means as COLUMNS "reverse engineers" it. This competition had TWO original datasets (stated by S5E6-10; 1st names only `original.csv`).
- **Features:** all pairs of 8 columns = 28, all triples = 56, all quadruples = 70 -> 162 = 8+28+56+70 categorical combination columns.
  - cuML Target Encoder on each combo for the 7 binary targets (y==0? ... y==6?) = 1134 columns; the same TE computed on the original dataset = 1134 more -> 2268 columns into one XGBoost.
  - Original-data-as-columns formula (verbatim): `TE = original_data.groupby(CAT_COL)[TARGET].agg("mean")`, `TE.name = f"TE_{CAT_COL}_orig"`, `train = train.merge(TE, on=CAT_COL, how='left')`.
  - Author comment: pairs+triples+quadruples TE'd for 7 binary targets on both train.csv and original.csv ≈ 3000 features.
  - Encodings: everything treated as categorical. Dropped columns: not stated. GP/generated features: none stated.
- **Models:** 9 final members (author's list):
  - XGBoost cuDF-FE, data-as-columns, depth=4 (10 models on 100% data).
  - XGBoost cuDF-FE, data-as-columns, depth=10 (10 models on 100% data).
  - Stacking NN over many stage-1 models (25 models trained).
  - XGBoost RepeatedStratifiedKFold, data-as-rows, public notebook by @bizen250 (50 XGB trained).
  - Stacking XGB over LGBM, public notebook by @ayushchandramaurya (multiple seeds).
  - XGBoost, data-as-rows, depth=18, public notebook by @elainedazzio (multiple seeds).
  - NN, public notebook by @ricopue Keras all-embedding (100 NNs trained).
  - Stacking XGB over many stage-1 models with pseudo-label COLUMNS (i.e. KNN features).
  - NN with pseudo-label ROWS (25 NNs).
  - Stage-1 of the stacks: XGBoost, CatBoost, NN, cuML Linear Regression per binary class; L2 = NN with categorical cross-entropy and XGB `objective='multi:softprob'`; the average of NN-L2 + GBDT-L2 beats either alone (author's words).
  - Boosting over residuals: cuML Linear Regression first, then XGBoost starts from its logits via `dtrain.set_base_margin(LINEAR_REGRESSION_LOGITS)`.
  - Per-model hyperparameters beyond depths and objectives: not stated.
- **CV:** 5-fold is the stated unit (average MAP@3 of a single 5-fold XGB's folds = 0.376; averaged probabilities of 100 such 5-fold XGBs = 0.380, +0.004 author figure).
  - Final CV MAP@3 = 0.386 vs Public 0.38450 (-0.0015) vs Private 0.38652 (+0.00052).
  - Trust verdict: "I chose my best CV ensemble which was also my best LB score."
- **Ensembling:** GPU hill climbing determines the 9 member weights (technique from his S5E5 win).
  - Each member trained many times with different seeds; final ensemble ≈ 300 sets of predictions averaged/weighted.
  - Repeated-seed averaging before top-3 selection is the metric-specific lever: MAP@3 is sensitive to training randomness (concept credited to bizen250's public notebook).
  - Author comment: the cuDF-FE "monster model" boosted an ensemble of public notebooks from CV 0.384 to 0.386 — "this diverse model was probably the secret sauce".
- **Post-processing:** pseudo-labeling in the final days (test rows labeled with the best ensemble; NNs consume soft probabilities natively, XGB via a custom soft-target multi-class objective).
  - Final retrain on 100% train: XGB gets fixed iterations = average early-stopping point + 25%; NN gets a fixed-step schedule from the average ReduceLROnPlateau point of the 5-fold runs.
  - Top-3 class ordering taken from averaged probabilities is the submission format itself.
- **Gains:** (+0.004 CV) averaging probabilities over 100 seeds of the same 5-fold XGB before selecting top-3 (0.376 fold-average -> 0.380 ensemble).
  - (+0.002 CV) adding the cuDF-FE monster model on top of a public-notebook ensemble (0.384 -> 0.386, author comment).
  - (unquantified) original-data target encoding as columns — the first model he built and the one he credits for the win ("This diverse model combined with public notebooks boosted me to 1st place").
  - (unquantified) NN-L2 + XGB-L2 average beats each L2 individually.
- **Failed:** a single model was never strong enough here — his own surprise; he expected to repeat the S5E2 single-model win ("I thought I could build another single model here. But a single model was never strong enough here", author comment).
  - TE beyond `mean`: tried std/min/max/skew subsets — "the improvement was not enough to justify so many new features" (mean alone is ~3000 features; full stat set would be ~15,000); for the binary y==k targets, `min` is always 0 and `max` always 1, so those stats carry no information.

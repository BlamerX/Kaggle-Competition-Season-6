### S5E4-01 · 1st · Chris Deotte (cdeotte) · LB 11.51/11.44 · CV 11.54 (final stack)

- **Link:** https://www.kaggle.com/c/playground-series-s5e4/discussion/575784
- **Status:** FETCHED on 1st try (`/c/` + `/discussion/` form returns body + 122 comments)
- **TL;DR:** 3-level RAPIDS cuML GPU stack; the winning structure was a stack precisely because a linear hill-climb blend cannot switch between "ELM present" and "ELM missing" rows.
- **Architecture:** STACKN · stages=3 · l1=75 models (12 base families × ~6 variations; 73 feed level 2) ·
  l2=2 meta-models: GBDT XGBoost + NN-MLP, each trained on the 73 L1 OOF/test-pred columns (both CV 11.56) ·
  novel=TabPFN · mod=multi-view,pseudo,cascade ·
  topo=75 GPU L1 models [same 5 KFolds] → XGB-L2 + MLP-L2 (OOF matrix) → level-3 weighted average 50%/50% → 11.54
  - Level 3 is a plain 50/50 average of the two level-2 outputs, not a third fitted meta-learner, but it is a third model layer, hence STACKN not STACK2.
  - `cascade`: several L1 members are "GBDT — Boost over RAPIDS Lasso/SVR/NN-MLP" that predict their base model's residuals (CV 11.9 each), so an earlier stage's output feeds a later model.
  - `pseudo`: pseudo-labeling with train+test rows is one of the 5 diversity generators.
- **Setup:** target `Listening_Time_minutes`; 10 features (9 modulators + ELM; author: "The other 9 features modulate this linear relationship"); 5 KFolds shared by every model; author's GPU = 3xA100.
  - Structural quirk exploited: ELM has 90%+ of signal but is NaN on 11.6% of rows → two sub-problems (predict with ELM / predict without ELM) that only a non-linear L2 can route between.
- **Features:** not published as a named list — author's method is "different engineered feature sets per model" (some L1 models use up to 6000 features for Lasso/SVR).
  - Ratio target: `train['new_target'] = Listening_Time_minutes / Episode_Length_minutes` (generator 3).
  - ELM-as-target: train models to predict ELM from train+test, then (a) impute missing ELM, (b) replace every ELM with the prediction, (c) multiply ELM-pred by ratio-pred (generator 4).
  - ELM-removed models: drop ELM from all rows to specialize on the missing case (generator 2).
  - L2 also receives hand-engineered columns next to the L1 OOFs; one is `df['ELM_nan'] = df.Episode_Length_minutes.isna().astype('float')` (author comment).
  - GP/generated features, encodings, dropped columns: not stated.
- **Models:** level-1 CV ladder (no pseudo labeling, author's table):
  - RAPIDS cuML Lasso (6000 features) 13.2
  - RAPIDS cuML SVR (6000 features) 13.2
  - RAPIDS cuML KNN Regressor (k=51, weight by distance) 12.8
  - RAPIDS cuML Random Forest (max_depth=32) 12.1
  - NN-MLP (built by ChatGPT) 12.0
  - NN-TabPFN (20× `SUBSAMPLE_SAMPLES: 10_000`) 13.2
  - GBDT XGBoost (4× models / 4× feature sets) 11.8
  - GBDT LGBM (diversified from XGB) 11.8
  - GBDT boost-over-Lasso / boost-over-SVR / boost-over-MLP residuals 11.9 each
  - AutoML AutoGluon (public notebook) 12.4
  - Level-2: XGBoost on 73 L1 → 11.56; NN-MLP on 73 L1 → 11.56. Level-3: 50/50 weighted average → 11.54.
  - MLP detail (author comment): 10 epochs, reduce-on-plateau LR schedule, batch 512, start LR 1e-3, Adam; Dense(512)→BN→ReLU→Drop0.3 → Dense(256)→BN→ReLU→Drop0.3 → Dense(128,relu) → Dense(1,linear). NN features = strongest GBDT's features, one-hot the categoricals, z-normalize numerics, impute missing to 0.
- **CV:** 5 KFold (author comment: "CV was 5 KFold"), same folds for every model; leaks removed from target encoding / pseudo labeling.
  - CV vs LB gap small and same sign: CV 11.54 → Public 11.51 → Private 11.44 (LB is 0.03–0.10 BETTER/lower than CV).
  - Trust verdict: CV tracks LB tightly ("The LB scores are basically the same as the CV scores").
- **Ensembling:** level 3 = 50%/50% average of the two level-2 models.
  - Hill climbing explicitly REJECTED as final: it is linear and would only weighted-average the with-ELM and without-ELM models instead of selecting between them.
  - Post-competition comparison (author's own 73× L1 pool): Hill Climbing CV 11.64 / Public 11.57 / Private 11.503 vs Stack CV 11.54 / Public 11.51 / Private 11.448 — the stack won by −0.10 CV and −0.055 Private.
  - Weaker L1 members are kept on purpose: models with CV ~26 RMSE (all-columns-except-ELM) still boost the stack (author comment).
- **Post-processing:** not stated (no clipping/threshold/rounding mentioned).
- **Gains:** (−0.10 CV, −0.055 Private) stacking vs hill climbing on the identical 73-model pool (biggest reported structural delta).
  - (−0.24 CV) two level-1 GBDTs at 11.8 → level-2 XGB/MLP at 11.56.
  - (−0.02 CV) level-2 11.56 → level-3 50/50 average 11.54.
  - (unquantified) first stack: training XGB on the OOF+test-preds of all prior experiments "jumped me into first place LB".
- **Failed:** hill climbing / ridge as the level-2 blender (linear → cannot route between ELM-present and ELM-missing rows).
  - TabPFN (CV 13.2), Lasso/SVR (13.2) and KNN (12.8) are weak L1 members kept only for diversity, not for score.
- **Comments:** 122 comments; technical content lives in author replies (mined above): MLP architecture + training recipe; 5 KFold; `ELM_nan` flag added to L2; "it's all about diversity, nothing about performance" (models with CV 26 RMSE help the stack); XGB ~10× faster on GPU, LGBM needs a recompile to use GPU well; best public single notebook used `max_depth=19` (why the data needs deep interactions); he spent 1–4 hours/day for a month; a single heavily-FE'd model (CV/LB 12.5) was beaten by public AutoGluon (12.4) — his early signal that one model was not enough.

### S5E4-03 · 3rd · Johannes Heller (stopwhispering) · LB not stated/not stated · CV 11.62 (stack, last-minute)

- **Link:** https://www.kaggle.com/c/playground-series-s5e4/discussion/575862
- **Status:** FETCHED
- **TL;DR:** Target-encoding-heavy 3-level stack, adopted at the last minute: stacking gave an immediate −0.04 CV on the first and only try, so the final submission is 80% stack + 20% hill-climb.
- **Architecture:** STACKN · stages=3 · l1=26 weighted L1 models (from ~100 trained; 10 LGBM + 5 XGB + 4 CatBoost + 2 RandomForest + 1 ExtraTrees + 4 HistGradientBoosting) ·
  l2=Hill Climbing + LGBM (LGBM fitted on the L1 OOF matrix) ·
  novel=none · mod=multi-view,neg-weights ·
  topo=26 diverse GBMs [same 5 KFolds] → Hill-Climb ensemble + LGBM-stack (L2) → weighted average 80% stack / 20% hill-climb (L3)

  - The Hill-Climb branch is a `FLAT` weight-search (ruling 1); the LGBM-on-L1-OOF branch is the trained meta-learner, which is what promotes the whole thing to a stack.

  - Mean TE beat median/min/max/nunique.
  - TE built by concatenating 2- to 7-grams after converting all columns to string; TE features with very high or very low cardinality dropped.
  - Custom TE implementation (no smoothing, no fillna).
  - Fixing extreme outliers in Number_of_Ads and Episode_Length_minutes helped.
  - Number of decimal digits of string-formatted Episode_Length_minutes added as a feature (credit to AngelosMar) — worked slightly better than correcting predictions post-hoc.
  - Some Divide/Minus/Plus/Combine interaction features.
  - Original dataset concatenated as extra rows; original records ignored when scoring CV; added flag `is_original`.
  - Feature selection: greedy Sequential Feature Selection with a high-learning-rate / low-`n_estimators` LGBM — score all, keep best ~10-20, repeat; removed extremely high-correlation features.
- **Models:** best single-model CV per family: LGBM 11.79, XGB 11.81, CatBoost 11.93, ExtraTrees 11.96, HistGB 11.99, RandomForest 12.05.

- **CV:** 5-fold simple KFold, fixed `random_state`; author believes 7 or 10 folds could have helped but rejected the runtime tradeoff. CV value of the final submission not published (the −0.04 stacking step is the only CV delta quoted).
- **Ensembling:** hill climbing via Nelder-Mead (Scipy) or the author's own implementation for most of the comp; weights can be positive or negative.

  - Final = 80% stacking ensemble + 20% best hill-climb ensemble.
  - Saved every OOF/test-pred as parquet from the start; periodically removed OOFs given zero weight to speed up hill climbing; even pre-TE early OOFs retained nonzero weight.
